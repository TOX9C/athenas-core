# Athena's Core: Architecture & Integration Guide

This file was generated by Agent 4 to help Agents 1, 2, and 3 understand the codebase architecture and coordinate their feature development without conflicts.

## Project Structure & Architecture

Athena's Core is an Electron application built with React, Vite, and TypeScript.

- **Frontend/UI State**: Handled by **Zustand** stores in `src/store/`.
- **Styling**: Tailwind CSS, utilizing `var(--bg)` CSS variables for theming.
- **Layout**: Utilizes `react-resizable-panels` in `src/App.tsx` for panel management.
- **IPC Communication**: Handled through `electron/preload.ts` mapped to `window.athena`.

## Key Files & Patterns

### 1. State Management (`src/store/`)

- `athenaStore.ts`: Global Athena assistant state (model, bypass mode, custom agents).
- `workspaceStore.ts`: Manages spaces, panes, and layout state.
- `uiStore.ts`: Manages sidebar, settings modal, active panels (`terminals`, `kanban`, `swarm`), and theme.
- `terminalStore.ts`, `editorStore.ts`, `taskStore.ts`: Domain-specific stores.

### 2. Frontend React Components (`src/components/`)

- **`src/App.tsx`**: The main entry point. Houses the top drag region/titlebar, sidebar navigation, and the main workspaces (`EditorPanel`, `BrowserPanel`, `KanbanBoard`, `SwarmBoard`, `TerminalGrid`, and `AthenaPanel`).
- **`src/components/Terminal/`**: Connects xterm.js to the node-pty backend.
- **`src/components/Athena/`**: Central assistant components.

### 3. Backend Electron Architecture (`electron/`)

- `electron/main.ts`: Main process entry point.
- `electron/ptyManager.ts`: Manages `node-pty` terminal instances. Emits events back to the frontend.
- `electron/athenaOrchestrator.ts` / `electron/swarmCoordinator.ts`: Backing logic for agents and multi-agent "swarms".
- `electron/preload.ts`: Crucial for bridging Backend PTY/FS/Window events to Frontend React events.
