# Athena API-Driven Orchestrator Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the Athena sidebar from a raw CLI PTY wrapper into a direct API-driven orchestrator. Athena will use the Anthropic API directly with a strict System Prompt to remain concise ("Done.") and will be equipped with tools to launch autonomous Claude Code CLI instances in the background.

**Architecture:**

1. Replace Athena's `node-pty` backend with the `@anthropic-ai/sdk`.
2. Define `electron/athenaOrchestrator.ts` to manage the Chat API context and Tools.
3. Expose a tool `launch_agent` to the API to let Athena spawn background tasks using the existing `ptyManager`.
4. Update `useAthena.ts` to rely on simple async IPC handles (request/response) instead of streaming noisy PTY data.

**Tech Stack:** React, Electron IPC, `@anthropic-ai/sdk`

- [ ] **Step 2: Create the Orchestrator service stub**
      Create `electron/athenaOrchestrator.ts`:

```typescript
import Anthropic from '@anthropic-ai/sdk'
// Will use an environment variable or store for the API key
const apiKey = process.env.ANTHROPIC_API_KEY || ''
const anthropic = new Anthropic({ apiKey })

export class AthenaOrchestrator {
  private messages: any[] = []

  async sendMessage(userText: string): Promise<string> {
    this.messages.push({ role: 'user', content: userText })

    // Stub for now. Next task will add system prompts and tools.
    const response = await anthropic.messages.create({
      model: 'claude-3-5-sonnet-20241022',
      max_tokens: 1024,
      messages: this.messages,
    })

    const replyText = response.content[0].type === 'text' ? response.content[0].text : 'Done.'
    this.messages.push({ role: 'assistant', content: replyText })
    return replyText
  }
}

export const athenaOrchestrator = new AthenaOrchestrator()
```

### Task 3: IPC Bridge Updates

**Files:**

- Modify: `electron/main.ts`

- [ ] **Step 1: Create new IPC handler for Athena Chat**
      In `main.ts`, expose the new Orchestrator to the renderer, replacing/bypassing `pty:spawn` specifically for Athena chats:

```typescript
import { athenaOrchestrator } from './athenaOrchestrator';

ipcMain.handle('athena:chat', async (_event, message: string) => {
  try {
    const reply = await athenaOrchestrator.sendMessage(message);
    return reply;
  } catch (error: any) {
    return \`Error: \${error.message}\`;
  }
});
```

const handleSubmit = async (text: string) => {
  addMessage({ id: Date.now(), role: 'user', content: text })

  // New simple IPC call! No dirty PTY stream!
