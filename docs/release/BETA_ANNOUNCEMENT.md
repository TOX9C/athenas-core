# Athena's Core — Beta Announcement

**Subject: Athena's Core beta is ready 🚀**

Hey! I've been building **Athena's Core** — a native macOS IDE for AI-assisted coding —
and the first beta is ready to test.

**What it is:** a desktop workspace with a real terminal, a Kanban board, a "Swarm"
for running AI agents in parallel, a built-in browser panel, and a plugin system for
developer integrations. Everything runs locally on your Mac.

**Requirements:** Apple Silicon Mac (M1/M2/M3/M4), macOS 13.0 or later.

**Two files:**

1. `Athena's Core_0.3.0_aarch64.dmg`
2. `BETA_INSTALL_INSTRUCTIONS.md` — **read this first**. The first launch needs a
   right-click → Open, because this is an unsigned beta (macOS shows a warning).

**What I need from you:** just use it. If anything freezes, crashes, or a button does
nothing, tell me **what you did, what you expected, and what happened**. Even "it
worked fine for 2 hours" is useful.

Thanks for helping! 🙏
