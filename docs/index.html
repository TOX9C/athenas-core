Features

Everything you need,
nothing you don’t.

Multi-pane terminal

A grid of native PTY sessions — 1×1 up to 4×4 — with full ANSI/VT100 emulation and 24-bit true color. Smart shell tracking via OSC 633.

Workspace-aware AI chat

Anthropic Claude, OpenAI, NVIDIA NIM, or local models via LM Studio. Every message carries a live snapshot of your workspace, agents, and plans. Tool calls, image attach, inline agent spawning.

Agent swarm

Launch teams — Coordinator, Builder, Scout, Reviewer — on a shared mailbox bus. Real-time status, state persisted to disk, stalled agents auto-detected.

Kanban task board

Four columns, per-workspace isolation, agent assignments. A task placed on a card becomes the agent’s next move.

Plugin system

Extend with JSON manifests. Capability scoping, per-agent plugin sessions with lifecycle tracking, an event bus, security validation against rules.

And the rest

⌘K command palette with fuzzy search. Embedded browser panel. Seven notification types, 500 stored. Sixteen themes, system auto-detect, live font preview.

Architecture

Native where it counts.

The backend is a Tauri 2 binary — a tiny app shell and 95 typed IPC commands. The frontend is a Dioxus WASM app rendered in the platform WebView. No bundled Chromium. No Node runtime.

The ambition is smallness: one release binary, three platforms, a footprint measured in single-digit megabytes, memory a fraction of an Electron app doing the same work.

$ cargo tauri build   # one binary · three platforms
  • src-tauri app shell · 95 IPC
  • athena-frontend Dioxus WASM · 85+ parts
  • athena-core LLM · MCP · agents
  • athena-terminal PTY · ANSI/VT100
  • athena-store KV + session (SQLite)
  • athena-fs filesystem · path guard
  • athena-browser embedded webview
  • athena-plugins manifest · security

Get Started

Build it from source.

Athena’s Core runs on macOS, Linux, and Windows. Clone, build the frontend, run the Tauri binary.

shell — quick start 
# Clone the repository
git clone https://github.com/TOX9C/athenas-core.git
cd athenas-core

# Build the frontend assets (release mode)
bash frontend/build-dist.sh

# Run in development mode
cargo run --manifest-path src-tauri/Cargo.toml

# Or use the Tauri CLI for hot-reload
cargo tauri dev

# Full release build
bash frontend/build-dist.sh && cargo tauri build

Prerequisites: Rust 1.82+, Node 18+, Tauri CLI, Dioxus CLI. · Platform deps → · Releases →
