The collection

Six native instruments,
under one roof.

Not a bundle of plugins bolted onto a vendor editor. Each layer is written in Rust, aware of the others, and built for the work — not for the screenshot.

  1. i

    Multi-pane terminal

    A grid of native PTY sessions — 1×1 up to 4×4 — with full ANSI/VT100 emulation and 24-bit true color. Smart shell tracking for zsh, bash, and fish via OSC 633.

    VT100true-colorOSC 633PTY
  2. ii

    Workspace-aware chat

    Anthropic Claude, OpenAI, NVIDIA NIM, or local models via LM Studio. Every message carries a live snapshot of your workspace, agents, and active plans. Tool calls, image attach, inline agent spawning.

  3. iii

    Swarm coordination

    Launch teams — Coordinator, Builder, Scout, Reviewer — on a shared mailbox bus. Status in real time, state persisted to disk, stalled agents auto-detected.

  4. iv

    Kanban tasks

    Four columns, per-workspace isolation, agent assignments. A task placed on a card becomes the agent’s next move.

  5. v

    Plugin system

    Extend with JSON manifests. Capability scoping, per-agent plugin sessions with lifecycle tracking, an event bus, security validation against rules.

  6. vi

    The rest of the workshop

    Embedded browser panel. Seven notification types — 500 stored. ⌘K command palette with fuzzy, recent-first surfacing. Sixteen curated themes, system auto-detect, live font preview.

The foundation

Native where it counts.

The backend is a Tauri 2 binary — a tiny app shell and 95 typed IPC commands. The frontend is a Dioxus WASM app rendered in the platform WebView. No bundled Chromium. No Node runtime.

The ambition is smallness: one release binary, three platforms, a footprint measured in single-digit megabytes, memory a fraction of an Electron app doing the same work.

$ cargo tauri build   # one binary · three platforms

  • src-tauri app shell · 95 IPC
  • athena-frontend Dioxus WASM · 85+ components
  • athena-core LLM · MCP · agent comms
  • athena-terminal PTY · ANSI/VT100 emulator
  • athena-store KV + session store (SQLite)
  • athena-fs filesystem · path protection
  • athena-browser embedded webview
  • athena-plugins manifest · security validation

Erect it

Build it from source.

Athena’s Core runs on macOS, Linux, and Windows. Clone, build the frontend, run the Tauri binary.

shell — quick start 
# Clone the repository
git clone https://github.com/TOX9C/athenas-core.git
cd athenas-core

# Build the frontend assets (release mode)
bash frontend/build-dist.sh

# Run in development mode
cargo run --manifest-path src-tauri/Cargo.toml

# Or use the Tauri CLI for hot-reload
cargo tauri dev

# Full release build
bash frontend/build-dist.sh && cargo tauri build
