The Pantheon

Every tool, under one roof.

Eight pillars hold up the workspace — each native, each aware of the others, none bolted on. Built in Rust and rendered in the webview.

Multi-pane Terminal Grid

A flexible terminal workspace with full ANSI/VT100 emulation, powered by a custom Rust terminal emulator. Automatic grid layouts from 1×1 up to 4×4, smart shell tracking for zsh, bash, and fish via OSC 633, and 24-bit true-color support.

AI Chat Assistant

Workspace-aware AI powered by multiple LLM providers — Anthropic Claude, OpenAI, NVIDIA NIM, or local models via LM Studio. Every conversation carries a live snapshot of your workspace, agents, and active plans. Attach images; call tools; spawn agents.

Kanban Task Board

Keep track of development tasks with a built-in Kanban board — four columns (To Do, In Progress, In Review, Complete), per-workspace isolation, and agent assignments. Tasks can be assigned directly to AI agents working in the swarm.

Swarm Multi-Agent Coordination

Launch and coordinate teams of AI agents — Coordinator, Builder, Scout, Reviewer roles — that communicate through a shared mailbox bus. Watch agent status in real time; state persists on disk; stalled agents are auto-detected.

Plugin System

Extend the workspace with custom plugins defined by simple JSON manifests. Capability scoping, per-agent plugin sessions with lifecycle tracking, an event bus, and automatic security validation against rules.

Browser Panel

Browse the web without leaving your workspace — a full embedded webview inside a resizable sidebar. Back, forward, reload with full history; dangerous schemes and empty URLs are rejected; external links open in your native browser.

Notification System

Seven notification types — info, warning, error, success, needs input, task complete, task error — many with action buttons. Up to 500 stored in history with unread tracking and filtered views; real-time as events occur.

Command Palette & Themes

⌘K fuzzy-searches every command with recent-first surfacing and full keyboard navigation. 16 curated dark and light themes inspired by modern IDEs and cultural aesthetics, with system auto-detect and live font preview.

The Foundation

Native where it counts,
web-native where it shows.

A clean split between the Tauri app shell and a family of focused Rust crates. The WebView renders the Dioxus/WASM frontend; the native backend handles every system-level operation — PTY, filesystem, LLM orchestration, MCP, and plugins.

Athena's Core is built with Rust and Tauri 2, delivering native performance with a modern web-tech frontend. The result is a compact ~15MB binary footprint and significantly lower memory usage than Electron-based applications — no bundled Chromium, no Node runtime.

The frontend is a Dioxus 0.7 WASM app — 85+ components and 15 stores rendered in the platform WKWebView. The backend exposes 95 typed IPC commands and a layer of workspace crates, each with a single responsibility.

Quick Start

Build it from source.

Athena's Core builds on macOS, Linux, and Windows. Clone the repo, build the Dioxus frontend assets, and run the Tauri binary.

shell — Athena's Core quick start
# Clone the repository
git clone https://github.com/TOX9C/athenas-core.git
cd athenas-core

# Build the frontend assets (release mode)
bash frontend/build-dist.sh

# Run the application in development mode
cargo run --manifest-path src-tauri/Cargo.toml

# Or use the Tauri CLI for hot-reload
cargo tauri dev

# Full release build
bash frontend/build-dist.sh && cargo tauri build

Prerequisites: Rust 1.82+, Node 18+, Tauri CLI, Dioxus CLI. Platform deps →  ·  Releases ↗
