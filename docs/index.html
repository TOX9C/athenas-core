The strategist’s workbench.

One window. Every tool. No noise.

Athena’s Core puts your terminal, AI chat, task board, and agent team in a single native window. What you just watched is what it does all day — for real. ~15 MB. Rust. No telemetry.

  1.

    2. 
          
  2. 
            
            
    
              
    Chat with context
    
              
    Athena reads the workspace you are already looking at. No pasting paths, no restating the task — the conversation starts where you are.
    
            
    
          
    3. 
          
  3. 
            
            
    
              
    A visible next step
    
              
    Ideas become cards on a board your agents and your team can share. The plan stays on screen instead of in someone’s scrollback.

  4.

              v3.3.1
              
Beta, with agent activity detection

              August 2026
            

            

              

                Athena’s Core now sees which AI agents are running inside each pane. A gold dot
                marks an agent at work, a pulsing dot means thinking, amber means finished or
                waiting on you. Agents waiting for input or hitting errors ping you — the pane
                border pulses so nothing waits unseen.
              

              
Also in this build:

              
    
                
  • Multi-pane terminal: several shell sessions side by side
    • 
                
  • Workspace-aware AI chat: talk to Claude or other LLMs inline
    • 
                
  • Swarm orchestration: launch multiple agents on a shared goal
    • 
                
  • Kanban tasks, a plugin system, an in-app browser, and 12 themes
