# Athena's Core

This is the Tauri 2 + Dioxus migration workspace.

## Structure

- `src-tauri/` — Tauri backend application
- `crates/` — Workspace crates for core logic
- `src/` — Dioxus frontend (to be scaffolded)

## Commands

- `cargo tauri dev` — Start Tauri development server
- `cargo tauri build` — Build for production
- `cargo check` — Check all workspace crates
